以下是一些基本的 Markdown 语法示例，及其在 Inyo 主题中的样式效果。正文为霞鹜文楷 16px / 行高 2.0，元信息使用更纱黑体，标题为楷体加粗。站外链接会自动在新窗口打开：这是一个[外部链接示例](https://gohugo.io/documentation/)，站内链接如[宣纸与墨](/posts/paper-and-ink/)则留在当前页。

## 标题

### 语法

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

### 效果

# 一级标题

## 二级标题

### 三级标题

#### 四级标题

##### 五级标题

###### 六级标题

## 段落

### 语法

在文本前添加井号 `#` 与空格，即可创建标题。使用空行分隔文本，即可创建段落。

```markdown
孔乙己一到店，所有喝酒的人便都看着他笑，有的叫道："孔乙己，你脸上又添上新伤疤了！"他不回答，对柜里说，"温两碗酒，要一碟茴香豆。"便排出九文大钱。

听人家背地里谈论，孔乙己原来也读过书，但终于没有进学，又不会营生；于是愈过愈穷，弄到将要讨饭了。
```

### 效果

孔乙己一到店，所有喝酒的人便都看着他笑，有的叫道："孔乙己，你脸上又添上新伤疤了！"他不回答，对柜里说，"温两碗酒，要一碟茴香豆。"便排出九文大钱。他们又故意的高声嚷道："你一定又偷了人家的东西了！"孔乙己睁大眼睛说："你怎么这样凭空污人清白……"

听人家背地里谈论，孔乙己原来也读过书，但终于没有进学，又不会营生；于是愈过愈穷，弄到将要讨饭了。

## 图片

### 语法

使用感叹号 `!` 方括号 `[]` 与圆括号 `()`，即可添加图片。这些都是半角符号，而非全角符号。

```markdown
![图片描述](https://image.example.com/example.jpg)
```

### 效果

本主题的图片会自动缩放，点击可查看大图。以下为站内示例（双鱼太极 logo）：

## 块引用

### 多个段落

#### 语法

```markdown
> 天地不仁，以万物为刍狗。
>
> **提示**：引用块内可使用 _Markdown 语法_。
```

#### 效果

> 天地不仁，以万物为刍狗。
>
> **提示**：引用块内可使用 *Markdown 语法*。

### 标注引用来源

使用 `<cite>` 或 `<footer>` 标签标注引用来源，同时可通过 `[^1]` 或 `[^note]` 格式插入脚注。

#### 语法

```markdown
> 在我的后园，可以看见墙外有两株树，一株是枣树，还有一株也是枣树。
>
> —— <cite>《秋夜》[^1]</cite>

[^1]: 《秋夜》是鲁迅散文诗集《野草》中的第一首散文诗，创作于 1924 年。
```

#### 效果

> 在我的后园，可以看见墙外有两株树，一株是枣树，还有一株也是枣树。
>
> —— 《秋夜》[^1]

[^1]: 《秋夜》是鲁迅散文诗集《野草》中的第一首散文诗，创作于 1924 年。

## 表格

### 语法

使用三个或多个连字符 `---` 分隔标题，并使用管道符 `|` 分隔每列，即可创建表格。

```markdown
| 斜体 | 粗体 | 代码 |
| ---- | ---- | ---- |
| _斜体_ | **粗体** | `代码` |
| _斜体_ | **粗体** | `代码` |
```

### 效果

| 斜体 | 粗体 | 代码 |
| ---- | ---- | ---- |
| *斜体* | **粗体** | `代码` |
| *斜体* | **粗体** | `代码` |

本主题的表格仅保留横线（中式简净），无竖线、无背景斑马纹。

## 代码块

### 语法

使用三个反引号 ``` ``` ``` 包裹代码，即可创建代码块。在顶部的反引号后标注语言类型，例如 `html`、`javascript`、`css`、`go` 等，即可实现语法高亮。

```markdown
​```html
<!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="utf-8" />
    <title>HTML5 示例文档</title>
  </head>
  <body>
    <p>测试</p>
  </body>
</html>
​```
```

### 效果

```html
<!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="utf-8" />
    <title>HTML5 示例文档</title>
  </head>
  <body>
    <p>测试</p>
  </body>
</html>
```

## 数学公式

本主题内置 KaTeX，支持行内与行间公式（需在 frontmatter 开启 `math: true`）。

### 语法

```markdown
行内公式：$E = mc^2$

行间公式：

$$
\sum_{k=1}^{n} k = \frac{n(n+1)}{2}
$$
```

### 效果

行内公式：$E = mc^2$

行间公式：

$$
\sum_{k=1}^{n} k = \frac{n(n+1)}{2}
$$
