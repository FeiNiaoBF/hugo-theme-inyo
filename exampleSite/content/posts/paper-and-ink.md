Inyo（陰陽）的设计从一对颜色开始：**荼蘼白** `#F8F4F0` 与 **松烟墨** `#3B3A3E`。

## 纸

宣纸是暖的。它不是纯白，而是带一点米色的呼吸感。所有表面层级都由它派生：

| 层级 | 色值 | 用途 |
|---|---|---|
| 底色 | `#F8F4F0` | 页面 |
| 卡片 | `#F9F1DB` | 引用块 |
| 边框 | `#CCCDC8` | 分隔线 |

## 墨

> 墨分五色：焦、浓、重、淡、清。—— 中国画论

暗色模式用 **剑锋紫** `#3E3841` 做夜墨底，正文是月白。链接是**舌红** `#F19790`——朱砂在夜墨底上的提亮态。

## 代码

```python
def greet(name: str) -> str:
    """以墨为码，以屏为纸。"""
    return f"你好，{name}"
```
