# Inyo v2 — 日式现代简约重设计规格

> 状态: 待确认
> 决策来源: 用户审阅 v1 后反馈（UI 不协调、配色怪、窄、页脚信息密度高）
> 参考气质: pianpker / waterdrop / justin3go / baoyu.io（仅借鉴布局机制，不复刻配色与框架）

## 1. 背景与问题

v1 的居中单栏在真实使用中暴露出：

- 整体 UI 不够协调；印章 Logo 与字体与主题气质不搭
- 亮/暗两模式像两套设计——暗色"剑锋紫"底与亮色暖纸体系脱节
- 页面过窄；移动端不协调
- 页脚信息密度高，含竖排签名（阅读方向逆直觉）

## 2. 目标

- 日式现代简约：**右侧固定导航栏 + 左中内容区**
- 亮/暗为同一设计的昼夜两版（纸墨二元），暗色改用墨黑体系
- 首页本质是目录（标题 + 日期 + 阅读时间，无卡片无摘要）
- 保持长文容器 38–42em（取 40em）、行高 ≥1.8（保持 2.0）、正文横排
- 移动端（≤768px）侧栏折叠为顶部条，内容全宽协调
- 印章保留但重新设计：细线、克制
- 页脚降至一行，删除竖排签名与 `vertical_footer` 配置

## 3. 非目标

- 不引入任何框架、不新增 JS（主题切换仍是唯一内联脚本）
- 不做诗句动画（记录为二期需求，纯 CSS 实现）
- 不引入卡片、阴影、封面图、分页、年份分组
- 不改变 KaTeX / 数学、印章文字、seal_text/seal_style 配置语义

## 4. 布局系统

### 4.1 桌面（>768px）

```
┌───────────────────────────────┬────────────────┐
│ 内容区                        │ 右侧导航栏(粘性)  │
│ 左对齐，阅读列 40em            │ 宽 18em          │
│                               │ ┌────────────┐  │
│  [首页=目录 / 文章 / 关于]      │ │ 印章+站名     │  │
│                               │ │ 首页         │  │
│                               │ │ 文章         │  │
│                               │ │ 关于         │  │
│                               │ │ ☯ 主题切换    │  │
│                               │ │ © 2026 Inyo  │  │
│                               │ └────────────┘  │
└───────────────────────────────┴────────────────┘
```

- 右侧栏 `position: sticky; top: 0; height: 100vh`（纯 CSS，零 JS）
- 内容区 `margin-right: 18em`，内部阅读列 `max-width: 40em` 左对齐
- 导航栏自身加细右分隔线（`--border`），不用背景色块

**平板中间态（768–1000px）**: 18em 侧栏 + 40em 内容在 <1000px 会拥挤。此区间侧栏收窄至 `14em`（媒体查询实现），内容区同步缩 margin；>1000px 恢复 18em。

### 4.2 移动（≤768px）

- 右侧栏失去 sticky，变为普通顶部条：站名左、导航与 ☯ 右，可换行
- 内容区全宽 + 左右 `1.25em` padding，无 margin
- 阅读列 40em 在窄屏自然收缩

### 4.3 语义与标题

- 每页恰好一个 `<h1>`：首页用视觉隐藏的站点标题；文章/列表/关于页用页面标题
- 导航栏站名是链接/文本，不是标题元素
- 目录条目标题用 `<h2>`；文章页正文标题用 `<h1>`

## 5. 组件规格

### 5.1 导航栏（原 header 重构）

顺序（自上而下）：印章 + 站名 → 首页 / 文章 / 关于 → ☯ → © 行
- 站名: 宋体加粗 + 字距 2px
- 导航链接: 宋体 `0.92em` + 字距 1px；hover 变朱砂
- © 行: 更纱黑体小号，只显示 `© 年份 站名` + **RSS 链接**（`index.xml`，更纱黑体同款小字，色用驼色/hover 朱砂），无主题署名、无竖排

### 5.2 首页目录

- 可选 `_index.md` 导语（保留 `.prose` 渲染）
- 目录列表: 每行 = `<h2>` 标题 + 日期 + 阅读时间
- 标题墨色、hover 朱砂；日期/阅读时间用更纱黑体小号驼色
- **摘要策略**: 文章若有 `description` 则显示一行摘要（内容驱动，零配置开关）；无则纯标题。默认即如此，不新增参数
- 零篇显示本地化空状态；一篇/多篇自然处理；不分组

### 5.3 文章页

- 标题 `<h1>` + 元信息（日期、阅读时间、tags 保留）
- 正文 `.post-single` 容器 `40em`，行高 2.0
- TOC 保留在正文流内（`<details>` 或现 `.toc` 样式）
- 上一篇/下一篇保留

### 5.4 列表页 / 标签页 / 关于

- 同一壳：页面 `<h1>` + 条目列表（沿用 5.2 目录条目样式）
- tags 驼色描边小章保留

### 5.5 印章 v2（重新设计）

- 保留方印形态与朱砂红，**细线化**：
  - yang（阳文）: 边框 stroke-width 1.5，字 11px，无填充
  - yin（阴文）: 朱砂填充 + 纸色字
- `aria-label` 保留；尺寸在导航栏约 30px
- 重新生成 `static/img/seal-yang.svg`、`seal-yin.svg`

### 5.6 分隔线

- 删除全宽毛笔笔触（`.brush-divider`）在页脚的用法；首页目录如需分隔，用细线 `--border` 或留白
- `static/img/brush.svg` 与相关 CSS 按需删除或保留为文章页装饰（**待定：默认删除，简单优先**）

## 6. 配色 v2

### 6.1 原则

- **亮色 = 墨在纸上**（基本保留现有，只微调层级）
- **暗色 = 白墨在墨砚上**（推翻剑锋紫，改用墨黑体系）
- 全站仍只有一个情绪色: 朱砂红
- 所有新色实测 WCAG: 正文 ≥4.5:1、大文本 ≥3:1，记录进 DESIGN.md §2

### 6.2 亮色（保留，微调）

- 纸 `--paper: #F8F4F0` / 正文 `--ink: #1D1B1C` / 朱砂 `--cinnabar: #D92121`
- 驼色 `--camel: #66462A`、黛蓝 `--indigo: #2A3C5C` 不变
- 表面层级 `--srf-*` 微调以匹配新布局（边框用于侧栏分隔线）

### 6.3 暗色（新：墨黑体系）

**实测结论（WCAG 对比度，本次复测）**: 墨黑底必须取暗端——`#232323` 上朱红掉到 4.35 ❌。选 **墨色 `#1D1B1C`**（742 库真名，恰为亮色正文墨色）：

| 角色 | 色名 | HEX | 实测对比度 (on #1D1B1C) |
|---|---|---|---|
| 底色 | 墨色 | `#1D1B1C` | — |
| 正文 | 月白暖灰 | `#ECE6DC` | **13.80 ✅** |
| 链接/印章 | 朱红 | `#ED5126` | **4.74 ✅** |
| 标签/日期 | 晓灰 | `#D4C4B7` | **10.10 ✅** |
| 代码文字 | 云峰灰 | `#C1C8D6` | **10.20 ✅** |
| 代码块底 | 深墨 | `#232323`（或 #2C2C2C） | 云峰灰 on 深墨 ≥9.3 ✅ |

- **叙事闭环**: 亮 = 墨字在纸（墨色正文在纸底）；暗 = 白墨在墨（月白正文在墨色底）——暗底恰好是亮色正文色
- 朱红 `#ED5126`（4.74 ✅）取代舌红，真朱砂家族回归暗色模式，双模式朱砂温度轴统一
- 表面层级: 墨色 → 月白短路径 OKLCH 插值，重新实测
- 删除"剑锋紫"及依赖它的三条纪律（松烟墨禁用、卡片链接粉红、浅档文字限制）；新底色的使用纪律按实测重写（墨黑上链接全角色过 AA，原"粉红补救"条款自然消失）
- 文档联动: DESIGN.md 新增 **ADR-7「墨黑体系」**，ADR-2 标记为**已被取代**
